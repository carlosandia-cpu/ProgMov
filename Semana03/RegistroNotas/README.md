# Registro de Notas

Aplicación Android desarrollada en Kotlin utilizando Jetpack Compose para registrar las notas de cuatro cursos y calcular el promedio ponderado del estudiante.

## Funcionalidades

- Asignación de notas entre 0 y 20 mediante Slider.
- Visualización de la nota seleccionada en tiempo real.
- Opción para redondear el promedio final.
- Confirmación de notas mediante Checkbox.
- Botón de cálculo habilitado únicamente después de confirmar las notas.
- Cálculo automático del promedio ponderado.
- Clasificación del resultado mediante una observación.
- Cambio de color de acuerdo con el resultado obtenido.

## Cursos y pesos

| Curso | Peso |
|---|---:|
| Fundamentos de Programación | 20% |
| Programación Orientada a Objetos | 25% |
| Programación en Móviles | 30% |
| Base de Datos | 25% |

## Clasificación del promedio

- **17 a 20:** Excelente
- **13 a 16.99:** Aprobado
- **10 a 12.99:** En recuperación
- **Menor a 10:** Desaprobado
