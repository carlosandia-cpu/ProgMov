# TECSUP Fit

Aplicación móvil desarrollada con Kotlin y Jetpack Compose para consultar clases de gimnasio y reservar cupos.

## Opción seleccionada

Opción B — TECSUP Fit.

La aplicación utiliza un bottomBar para navegar entre sus secciones principales y presenta el siguiente flujo:

Inicio → Detalle de clase → Reserva → Confirmación

## Requisitos funcionales

### RF01 — Consultar clases disponibles

El usuario podrá visualizar una lista de clases disponibles con su nombre, horario y sala. También podrá filtrar las clases mediante las opciones "Hoy" y "Esta semana".

### RF02 — Consultar el detalle de una clase

El usuario podrá seleccionar una clase para visualizar su nombre, horario, sala, duración, descripción y cantidad de cupos disponibles.

### RF03 — Reservar un cupo

El usuario podrá seleccionar un horario disponible y reservar un cupo para la clase elegida. Después de reservar, la aplicación mostrará una pantalla de confirmación.

### RF04 — Consultar reservas realizadas

El usuario podrá visualizar sus reservas y diferenciar visualmente si se encuentran confirmadas o completadas.

## Navegación principal

El bottomBar contará con cuatro secciones:

- Inicio
- Reservas
- Rutinas
- Perfil
